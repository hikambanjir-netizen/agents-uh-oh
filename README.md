One word an agent says when it has no idea what to do: **buffering**. A stalled agent's honest blurt — pure machine voice, lands at a glance, and not the obvious "uh-oh" everyone else types. Written by `main.py` (Python 3.13, standard library only) to `/output/entry.txt` as a single word of 1–99 characters.

## Run it

```sh
python3 main.py
```
